# Scholar CLI MVP 范围与里程碑

## 1. 范围声明
MVP 范围 = `IMPLEMENTATION_PLAN.md` 的完整范围，不做收缩。

## 2. 阶段范围（Phase 0-7）
1. Phase 0（1 周）: 项目初始化
- Git 初始化、项目结构、开发工具、CI 基础。

2. Phase 1（2-3 周）: OpenCode 架构学习
- ReAct、ToolRegistry、SubAgent、MCP/Skills/Hooks、上下文管理。

3. Phase 2（4-6 周）: 核心工具开发
- 搜索、下载、PDF 处理、ReadPaper、引用管理与写作辅助。

4. Phase 3（3-4 周）: 文献记忆系统
- 存储结构、RESEARCH.md、分层上下文动态加载与压缩。

5. Phase 4（2-3 周）: Agent 核心集成
- Fork 与核心循环集成、工具注册、工作流编排。

6. Phase 5（1-2 周）: Git 工作流集成
- 实验与写作结果版本化管理。

7. Phase 6（3-4 周）: 测试与质量保证
- 单测、集成、E2E、回归、性能与质量门禁。

8. Phase 7（2-3 周）: 文档与部署
- 用户文档、开发文档、发布准备与部署流程。

## 3. 总周期
12-16 周（与实施计划一致）。

## 4. MVP Exit Criteria
1. Phase 0-7 对应交付物全部完成。
2. 验收场景端到端通过。
3. 覆盖率 > 80%。
4. 50 篇论文处理性能目标达标。
5. 用户与开发文档齐备。
